Star Trek RTS Design

Early design work for a fan-made Star Trek real-time strategy game for 1 to 4 players: colonize planets, moons, asteroids and stations across every era, as any of seven factions. These pages are built from the data files in the GitHub repository; all numbers are placeholders for balancing.

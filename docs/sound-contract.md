# Sounds: contract

Owner 2026-11-09: "add some sounds to the game. minor things. Like selecting a menu, landing mechanics. A hum for each
building or vehicle you select."

No sound library or recording is available here and nothing can be listened to, so every sound is **synthesised
offline** by a script into WAV files in the repo (replaceable later by real recordings with the same name). Render-only.

## Files (agent S1 makes them)

`tools/gen_sounds.py` (numpy + the stdlib `wave` module; no scipy), deterministic (fixed seeds), writes
`game/sounds/<group>/<name>.wav`, 16-bit PCM mono 44.1 kHz (loops: seamless, loop points = whole file; the importer
loop mode is set by Godot's `.import` or by code: S2 sets `LoopMode` in code on load, so no .import files need
committing). Peak-normalised to about −3 dBFS, quiet-to-loud balance chosen so UI < selection hums < landing.

- `ui/`: `hover`, `click`, `back`, `locked`, `open`, `close`, `confirm`, `error`, `tutorial` (card pops up),
  `tutorial_done` (step complete), `place` (building placed), `cancel`.
- `landing/`: `burn_loop` (rocket roar, loop, broadband), `burn_ignite`, `engine_cut`, `touchdown` (heavy thump +
  gear creak), `ramp_open`, `ramp_close` (hydraulic servo), `liftoff` (ignition crack + roar swell, one-shot ~3 s),
  `winch_loop` (cable pay-out, loop), `module_clamp` (metal clunk), `unfurl` (servo whirr + latch clicks, ~5 s),
  `uplink` (comms chirp sequence), `vehicle_roll` (unit driving down the ramp, short).
- `select/`: one per building/vehicle id, ~1–1.6 s, a "hum" with character: `colony_hub`, `storage_container`,
  `refinery`, `mine`, `fusion_reactor`, `prefab_habitat`, `foundry`, `deep_core_mine`, `vehicle_bay`, `science_lab`,
  `machine_shop`, `excavation_site`, `pressure_dome`, `life_support_plant`, `survey_team`, `survey_rover`,
  `survey_rover_mk2`, `survey_rover_mk3`, `mining_crawler`, `construction_rover`, plus `default_building`,
  `default_vehicle`. (Higher Colony Hub levels use `colony_hub`.)

Also a listening page: `docs/sounds/index.html` (generated by the script: every sound with an `<audio>` player,
grouped, names + one-line description; WAVs embedded as data URIs or downsampled previews, page ≤ 8 MB) so the owner can
audition them; published as a claude.ai artifact.

## API (agent S2; stub `game/scripts/Sfx.cs`)

Static `Sfx` with an autoload-free host: the first call creates a `SfxHost` node under the scene tree root (survives
scene changes: `GetTree().Root.AddChild`, deferred if needed).
- Buses created at runtime with `AudioServer` if missing: `UI`, `Effects`, `Ambience` (all to Master).
- `Sfx.Ui(string name, float volumeDb = 0, float pitch = 1)` — non-positional on bus UI; cached streams; a small
  player pool; `hover` rate-limited.
- `Sfx.At(string path, Vector3 position, float volumeDb = 0, float pitch = 1)` — one-shot `AudioStreamPlayer3D` on
  Effects (path like "landing/touchdown").
- `Sfx.Loop(Node3D parent, string path)` → `AudioStreamPlayer3D` the caller drives (VolumeDb, PitchScale, Playing).
- `Sfx.Select(string id, bool vehicle)` — the selection hum on Effects (non-positional, ducked if one plays); falls back
  to `default_building` / `default_vehicle`; a missing file = silence, never an error spam (one warning).
- `GameSettings`: add `UiVolume`, `EffectsVolume` (0..1, saved, applied to the buses) next to `MasterVolume`
  (which now really works); sliders in `SettingsPanel.cs` (remove the "no sounds yet" note).

## Hooks (agent S2)

- Menus: every Button in MainMenu / SettingsPanel / PauseMenu / HelmScreen action pills / build drawer tiles / command
  card / TutorialCard: hover + click (locked buttons `locked`, back/close `back`). Prefer one helper
  (`Sfx.Wire(Control root)` walking buttons once) over editing every button.
- Placing a building `place`, cancel `cancel`, refusals in the event feed `error` (rate-limited), tutorial card shown
  `tutorial`, step done `tutorial_done`.
- Landing (`DropShipView`, `LandingView`): burn loop per ship driven by throttle (volume + pitch), ignite/cut on throttle
  edges, touchdown, ramp open/close, vehicle roll, lift-off, winch while cables pay out, module clamp, unfurl, uplink at
  the swap. Positional (AudioStreamPlayer3D at the ship), attenuation sized to the landing camera (~170 away still
  clearly audible; max distance ~900). Only for ships that are shown.
- Selection: when the selection changes to one building or one kind of vehicle (or a base), play its hum once.

Achievements

/*READOUT*/

Every achievement of the game prototype, by category, as data/achievements/ defines it. Each one earns a cosmetic (a rover name, a hull number, a paint, a finish, a drop ship name, an exocomp beam colour or a dome tint), never anything that changes play. The simulation checks the rules about once a second of game time; nothing counts in test mode, with draft data or in the balance runner. Hidden ones show as question marks in the game until earned. All thresholds are fixed in the data.
